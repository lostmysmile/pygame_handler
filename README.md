# pygame handler system

## Usage in terminal

> `py -m pygame_handler.system.main` to run  
> `py -m pytest -v .` to test

### Checkout

Install either `pygame` or `pygame-ce`
> `python -m pip install -e ".[pygame-ce]"` to download
> `python -m pip install -e ".[test,pygame-ce]"`
